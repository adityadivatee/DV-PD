Getting Started with Divte Vault

Welcome to the official Divte Vault documentation. Follow this master guide to perfectly configure your secure environments and seamlessly deploy massive application archives.

1. Create Your Configuration

Navigate to the "Create New Vault" tab. Configure your environment parameters as follows:

  • Vault Name: Pick a clear identifier (e.g., Game_Project_01).
  • 1. Target Folder (Crucial): Select the exact directory on your hard drive where you want the application deployed (e.g., D:\SandboxApps). Divte Vault will map this directory directly into the secure container to ensure native read/write speeds.
  • 2. Temp Extraction Folder (For Massive Archives): If you are deploying a heavily compressed application archive, select an empty directory on a drive that has at least 150GB of free space. This forces the extraction engine to use this specific drive, preventing your host C: drive from reaching capacity and causing a system crash.

2. Select Your Engine

  • Sandboxie (High Performance): Best for installing and executing complex software and games. Maintains high frame rates while isolating the application from modifying your host Windows registry.
    WARNING: Do NOT use this for competitive multiplayer applications utilizing Kernel-Level Anti-Cheats (e.g., Vanguard, BattlEye). The isolation layer will trigger automated account bans.
  • Hyper-V (Maximum Security): Best for highly suspicious or untrusted software. Creates a temporary, hardware-isolated Windows Virtual Machine that is completely wiped from existence the moment the vault is closed.

3. The 14% Memory Limitation Fix

If you are deploying a heavily compressed archive and experiencing "ISDone.dll" memory allocation crashes during extraction, execute these exact parameters:

  1. Click the 3-dot menu (⋮) on your newly created vault and click "Fix Antivirus Block". This temporarily tunnels your Target Folder past Windows Defender heuristics so it doesn't silently quarantine unsigned custom binaries mid-extraction.
  2. Click Install on the Vault to initialize the setup executable.
  3. Inside the third-party installer window, you MUST check the parameter box that states "Limit installer to 2GB of RAM usage".
  4. Inside the installer window, you MUST browse and change the deployment path to exactly match your designated Target Folder (e.g., D:\SandboxApps).

4. Linking and Execution

Because Divte Vault perfectly traps your software inside a digital cage, the execution file is hidden from your host machine. Here is how to launch it:

  • Click the 3-dot menu (⋮) and select "Explore Vault". This launches an isolated File Explorer process allowing you to visually verify where your deployment files were trapped.
  • Once you locate the application's main .exe file, click the blue "Link Game/App" button on your Vault dashboard and target that executable.
  • Click the orange "Play/Run" button to securely initialize the application within the sandbox!

5. Critical Security Directives

SECURITY BREACH WARNING: Never copy, paste, or drag files from inside the isolated "Explore Vault" window back out to your host desktop! This completely bypasses the digital containment cage and allows trapped malware or untrusted scripts to instantly execute on your unprotected host machine.
