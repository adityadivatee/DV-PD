Getting Started with Divte Vault

Welcome to Divte Vault! Follow this master guide to perfectly configure your Vaults and seamlessly install massive game repacks securely.

1. Create Your Configuration

Navigate to the "Create New Vault" tab. Here is how you should configure your settings:

  • Vault Name: Pick a clear name (e.g., "Black Myth Wukong").
  • 1. Target Folder (Crucial): Select the exact folder on your hard drive where you want the game to be saved (e.g., D:\Games). Divte Vault will map this folder directly into the sandbox to ensure native performance.
  • 2. Temp Extraction Folder (For Massive Games): If you are installing a huge FitGirl repack, select an empty folder on a drive that has at least 150GB of free space. This aggressively forces the extraction engine to use this drive, protecting your C: drive from running out of space and crashing!

2. Select Your Engine

  • Sandboxie (Gaming): Best for installing and playing games. Maintains high frame rates while isolating the game from destroying your Windows registry.
    WARNING: Do NOT use this for competitive multiplayer games with Anti-Cheats (e.g., Vanguard, BattlEye). It will trigger an automatic account ban.
  • Hyper-V (Security): Best for highly suspicious software. Creates a temporary, hardware-isolated Windows Virtual Machine that is completely destroyed the moment it is closed.

3. The 14% Installation Fix (FitGirl Repacks)

If you are installing a heavily compressed game repack, follow these exact steps to avoid the dreaded "ISDone.dll" memory crashes:

  1. Click the 3-dot menu (⋮) on your new vault and click "Fix Antivirus Block". This temporarily tunnels your Target Folder past Windows Defender so it doesn't silently delete cracked files mid-extraction.
  2. Click Install on the Vault to run the installer.
  3. Inside the FitGirl window, you MUST check the box that says "Limit installer to 2GB of RAM usage".
  4. Inside the FitGirl window, you MUST browse and change the installation path to exactly match your Target Folder (e.g., D:\Games).

4. Linking and Playing

Because Divte Vault perfectly traps your game, the executable is hidden! Here is how to play:

  • Click the 3-dot menu (⋮) and select "Explore Vault". This launches an isolated File Explorer so you can visually see exactly where your game files were trapped.
  • Once you find the game's executable path, click the blue "Link Game" button on your Vault and select the executable.
  • Click the orange "Play" button to securely launch the game!

5. Security Warnings

Never copy, paste, or drag files from inside the isolated "Explore Vault" window back out to your real desktop! This completely bypasses the digital cage and allows viruses to immediately escape onto your real PC!
