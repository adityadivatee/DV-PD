Getting Started with Divte Vault

Welcome to Divte Vault! Follow these simple steps to isolate your applications.

1. Create a Vault

Navigate to the "Create New Vault" tab. Enter a recognizable name for your application. Select the target executable you wish to sandbox.

2. Select an Engine

  • Sandboxie: Best for games. Keeps everything isolated but maintains high frame rates and performance. Game saves persist in your Documents folder securely.
    WARNING: Do NOT use this for competitive multiplayer games with Anti-Cheats (e.g., Vanguard, BattlEye). It will trigger an automatic account ban.
  • Hyper-V (Security): Best for unknown software. Creates a temporary, hardware-isolated Windows environment that is completely destroyed when closed. Requires Windows 10/11 Pro or Enterprise.

3. Security Tips

Never copy, paste, or drag files from inside the isolated vault back out to your real desktop. This completely bypasses the sandbox protection and can cause immediate damage to your PC.

4. Launch and Manage

Go to "My Vaults". Click the green Play icon to securely launch the executable. You can also explore the isolated file system, wipe the data clean, or delete the vault entirely using the action icons.
