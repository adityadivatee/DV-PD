Privacy Policy

Effective Date: May 16, 2026

Provider: Aditya Diwate (operating as Aditya Divte Production)

At Aditya Diwate (operating as Aditya Divte Production), we take your privacy and system security extremely seriously. This policy outlines how data is handled when you use the Divte Vault website and desktop application.

1. Local Isolation Guarantee

Divte Vault is an offline-first desktop application. The core sandboxing technology (Sandboxie and Hyper-V) operates entirely on your local machine. We do not have access to, nor do we monitor, the files inside your vaults, the applications you run, or the contents of your host file system.

2. Telemetry & Analytics Data

To improve software stability and understand how our product is used, we utilize PostHog Analytics. This telemetry collects anonymized, non-sensitive metadata, including:

  • Application launch counts and session durations.
  • General system architecture (e.g., Windows OS version).
  • Usage statistics for specific UI buttons (e.g., Vault creation, engine selection).
  • Website page views and download button clicks.

We do not log keystrokes, personal file names, browsing history, or the specific names of the applications you are isolating.

3. Auto-Updater Communications

When the application launches, it makes a brief, encrypted HTTPS request to the public GitHub API (`api.github.com`) to check for the latest version tag. This request contains no personal identifier other than your standard IP address, which is processed directly by GitHub in accordance with their privacy policies.

4. Third-Party Engines

Divte Vault acts as a wrapper around Windows Hyper-V and Sandboxie-Plus. By using Divte Vault, your isolated instances are subject to the standard data policies of the Microsoft Windows operating system.

5. Contact Us

If you have any questions regarding this privacy policy or our data practices, please contact us at support@adityadivte.com or via our official GitHub repository.
